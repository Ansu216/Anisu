Drop the app font here. Anisu picks these up automatically (any that exist are used):

  ansu_sans_regular.ttf   (normal text, descriptions)
  ansu_sans_medium.ttf    (titles; optional, regular is used if missing)
  ansu_sans_bold.ttf      (headings; optional)

Use a clean sans-serif such as Roboto, Google Sans / Product Sans-style, or Inter (all free for
Roboto and Inter). With no files here the app falls back to the phone's own system font.
